# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Three.js with Vite and JavaScript. The user explicitly requested Three.js and confirmed building the museum directly following the proposed lightweight Vite setup.

## Users
Students and a presenter exploring wine history in a lesson, on desktop and phones.

## Product Purpose
A walkable interactive museum, using the supplied local objects and scenes. Selecting exhibits opens information that can support a live lesson.

## Capabilities and Constraints
English default interface with an Azerbaijani option; keyboard and touch navigation; sources outside the canvas; presentation route, timeline, map, shareable exhibit links and QR codes. GitHub Pages deployment workflow and setup guide. Generic models are illustrative, never evidence for a historical site. Existing research documents and original models are preserved.

## Evidence on Hand
The project brief, storyline, research leads and attribution register; a Roman amphora scan, generic amphora model, CC0 winery props and three illustrative scene prototypes. Unverified local archaeological claims remain explicitly unresolved.

## Accessibility & Inclusion
Readable HTML collection alongside the 3D view, keyboard navigation, focus visibility, reduced motion and low graphics settings.
